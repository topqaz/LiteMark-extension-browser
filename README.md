# LiteMark 浏览器扩展

一键将当前网页添加到 LiteMark 书签管理系统。

## 功能特点

- 🔖 **右键菜单添加**：在任意网页右键，选择"添加到 LiteMark"
- 🔗 **链接快速添加**：右键点击链接，直接添加到 LiteMark
- 📝 **选中文本添加**：选中文本后右键，将选中内容作为标题添加当前页面
- 🔐 安全的登录认证
- 💾 配置自动保存
- 🔔 操作结果通知提醒

## 安装说明

### Chrome 浏览器安装步骤

1. **下载扩展**
   - 访问 [LiteMark 扩展下载页面](https://github.com/topqaz/LiteMark-extension-browser/releases)
   - 下载最新版本的扩展压缩包（如：`LiteMark-extension-1.0.0.zip`）
   - 解压到任意一个地方（**注意：目录不能含有中文**）

2. **加载扩展**
   - 打开 Chrome 浏览器，点击右上角的"三个点"图标
   - 选择"扩展程序" → "管理扩展程序"
   - 在扩展程序页面，点击左上角的"开发者模式"切换开关，使其变成蓝色
   - 点击页面右上角的"加载已解压的扩展程序"
   - 选择你第一步中解压的文件夹

3. **完成安装**
   - Chrome 会加载这个扩展程序，你可以在扩展程序页面看到它已经被成功添加
   - 扩展图标会出现在浏览器工具栏中

### 其他浏览器

- **Edge 浏览器**：安装步骤与 Chrome 相同
- **其他 Chromium 内核浏览器**：参考 Chrome 安装步骤

## 使用方法

### 1. 首次配置

1. 点击扩展图标打开配置页面
2. 输入你的 LiteMark 部署地址（如：`https://your-litemark.app`）
3. 输入管理员用户名和密码
4. 点击"保存配置"

### 2. 添加书签

配置完成后，你可以通过以下方式添加书签：

#### 右键菜单

- **添加当前页面**：在任意网页空白处右键，选择"添加到 LiteMark" → 选择分类（或无分类）
- **添加链接**：右键点击页面中的链接，选择"添加到 LiteMark" → 选择分类
- **标题获取方式**：
  - **选中文本**：如果选中了页面中的文本，会使用选中文本作为书签标题
  - **网站标题**：如果没有选中文本，会使用网站标题（页面 `<title>` 标签内容）
  - **链接文本**：如果右键点击链接且没有选中文本，会使用链接文本作为标题
- **选择分类**：右键菜单会显示所有已存在的分类，选择后书签会添加到对应分类中

### 3. 操作反馈

- ✅ 添加成功：会显示浏览器通知，提示书签已添加（包含分类信息）
- ❌ 添加失败：会显示错误通知，提示失败原因
- ⚠️ 未配置：会提示先配置 LiteMark 地址和登录信息

### 4. 分类菜单

- 分类菜单会自动从 LiteMark 中加载所有已存在的分类
- 分类列表会缓存 5 分钟，以提高性能
- 新添加的分类会在下次右键时自动显示
- 如果还没有分类，菜单中只会显示"无分类"选项

## 开发说明

### 文件结构

```text
extension/
├── manifest.json      # 扩展配置文件
├── popup.html         # 弹出窗口 HTML
├── popup.css          # 弹出窗口样式
├── popup.js           # 弹出窗口逻辑
├── background.js      # 后台服务脚本（处理右键菜单）
├── icons/             # 扩展图标（需要自行添加）
│   ├── icon16.png
│   ├── icon48.png
│   └── icon128.png
└── README.md          # 说明文档
```

### 权限说明

- `storage`: 保存配置信息（使用 Chrome Storage Sync API）
- `contextMenus`: 创建右键菜单
- `tabs`: 获取当前标签页信息
- `notifications`: 显示操作结果通知
- `host_permissions`: 访问 LiteMark API

## 注意事项

1. 首次使用需要配置 LiteMark 地址和登录信息
2. 配置信息会保存在浏览器本地（Chrome Sync），不会上传到任何服务器
3. Token 会在本地缓存 1 小时，过期后会自动重新登录
4. 如果配置更改，Token 缓存会自动清除
5. 需要网络连接才能添加书签

## 故障排除

### 右键菜单不显示

- 检查扩展是否已正确安装和启用
- 尝试重新加载扩展（在扩展管理页面点击刷新）
- 检查浏览器控制台是否有错误（F12）

### 添加失败

- 检查 LiteMark 地址是否正确
- 检查用户名和密码是否正确
- 检查网络连接是否正常
- 查看浏览器控制台错误信息（F12）
- 查看扩展后台脚本日志（扩展管理页面 → 服务工作者）

### 通知不显示

- 检查浏览器通知权限是否已授予
- 在浏览器设置中允许该扩展显示通知
