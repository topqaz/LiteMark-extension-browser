# LiteMark 浏览器扩展

一键将网页添加到 LiteMark 书签管理系统，支持 AI 智能添加。

## 功能特点

- 🔖 **右键菜单添加**：在任意网页右键，选择"添加到 LiteMark"
- 🤖 **AI 智能添加**：使用 AI 自动生成标题、描述、标签和推荐分类
- 📥 **收藏夹导入**：一键导入浏览器收藏夹到 LiteMark
- 🔗 **链接快速添加**：右键点击链接直接添加
- 📝 **智能标题**：选中文本作为标题，或自动使用页面标题
- 🏷️ **分类管理**：自动加载分类，支持分类添加
- 🔔 **实时通知**：添加成功/失败即时反馈

## 快速开始

### 1. 安装扩展

#### Chrome / Edge 浏览器

1. **下载扩展**
   - 访问 [LiteMark 扩展下载页面](https://github.com/topqaz/LiteMark-extension-browser/releases)
   - 下载最新版本的扩展压缩包（如：`LiteMark-extension-2.0.0.zip`）
   - 解压到任意目录（**注意：目录不能含有中文**）

2. **加载扩展**
   - 打开浏览器，访问 `chrome://extensions/`（Edge 浏览器访问 `edge://extensions/`）
   - 开启右上角的"开发者模式"
   - 点击"加载已解压的扩展程序"
   - 选择解压后的扩展目录

### 2. 配置扩展

1. 点击浏览器工具栏上的 LiteMark 扩展图标
2. 输入你的 LiteMark 部署地址（如：`https://your-litemark.app`）
3. 输入管理员用户名和密码
4. （可选）勾选"🤖 启用 AI 智能添加"
5. 点击"保存配置"

### 3. 使用扩展

配置完成后，你可以通过以下方式添加书签：

#### 右键菜单添加

- **添加当前页面**：在网页空白处右键 → "添加到 LiteMark" → 选择分类 → "📝 直接添加"
- **AI 智能添加**：在网页空白处右键 → "添加到 LiteMark" → "🤖 AI 智能添加（完全自动）"
- **AI 分类添加**：在网页空白处右键 → "添加到 LiteMark" → 选择分类 → "🤖 AI 生成内容"
- **添加链接**：右键点击页面中的链接 → "添加到 LiteMark" → 选择分类

#### 标题获取方式

- **选中文本**：如果选中了页面中的文本，会使用选中文本作为书签标题
- **网站标题**：如果没有选中文本，会使用网站标题（页面 `<title>` 标签内容）
- **链接文本**：如果右键点击链接且没有选中文本，会使用链接文本作为标题

#### 导入浏览器收藏夹

1. 点击扩展图标打开配置页面
2. 滚动到"导入浏览器收藏夹"区域
3. （可选）勾选"使用文件夹名称作为分类"
4. 点击"开始导入"
5. 等待导入完成

## 功能详解

### 分类管理

- 分类菜单会自动从 LiteMark 中加载所有已存在的分类
- 分类列表会缓存 5 分钟，以提高性能
- 新添加的分类会在下次右键时自动显示
- 每个分类下有两个选项：
  - **📝 直接添加**：使用当前标题和 URL 直接添加
  - **🤖 AI 生成内容**：使用 AI 生成描述和标签（需启用 AI 功能）

### AI 智能添加

启用 AI 功能后，扩展会调用 LiteMark 后端的 AI API：

#### AI 添加模式

1. **🤖 AI 智能添加（完全自动）**
   - API: `/api/ai/quick-add`
   - 只提供 URL，AI 自动生成标题、描述、标签和分类
   - 适合快速收藏，完全自动化

2. **🤖 AI 生成内容（指定分类）**
   - API: `/api/ai/quick-add-with-category`
   - 提供 URL、标题和分类，AI 生成描述和标签
   - 适合已知分类，需要 AI 补充内容

3. **📝 直接添加**
   - API: `/api/bookmarks`
   - 不使用 AI，直接添加标题和 URL
   - 适合快速添加，无需额外信息

#### AI 功能特点

- ✅ 自动分析网页内容
- ✅ 生成优化的标题和描述
- ✅ 智能推荐合适的分类
- ✅ 自动提取关键标签
- ✅ 实时通知处理进度

#### 注意事项

- AI 功能需要 LiteMark 后端支持（v2.0+）
- 确保后端已配置 AI 服务（OpenAI、Claude 等）
- AI 处理可能需要几秒钟时间，请耐心等待
- 处理过程中会显示"🤖 AI 正在处理"通知
- 完成后会显示"🤖 AI 添加成功"通知

### 通知功能

扩展会在以下情况显示通知：

- ✅ **添加成功**：显示书签标题和分类（3秒后自动消失）
- 🤖 **AI 处理中**：显示"正在生成书签内容..."（直到完成）
- 🤖 **AI 添加成功**：显示书签标题、分类和标签（5秒后自动消失）
- ❌ **添加失败**：显示错误原因
- ⚠️ **未配置**：提示先配置 LiteMark 地址和登录信息

#### 通知权限设置

如果看不到通知，请检查系统设置：

**macOS 系统：**
1. 打开 **系统设置** → **通知**
2. 在左侧列表中找到 **Google Chrome**
3. 确保以下设置：
   - ✅ **允许通知** 开关已打开
   - 通知样式选择：**横幅** 或 **提醒**
   - ✅ **在通知中心显示** 已勾选

**Windows 系统：**
1. 打开 **设置** → **系统** → **通知**
2. 确保通知功能已开启
3. 找到 **Google Chrome** 并允许通知

**Chrome 浏览器设置：**
1. 访问 `chrome://settings/content/notifications`
2. 确保 **"网站可以请求发送通知"** 已启用

## 开发说明

### 文件结构

```text
LiteMark-extension-browser/
├── manifest.json      # 扩展配置文件（Manifest V3）
├── popup.html         # 弹出窗口 HTML
├── popup.css          # 弹出窗口样式
├── popup.js           # 弹出窗口逻辑
├── background.js      # 后台服务脚本（处理右键菜单和通知）
├── icons/             # 扩展图标
│   ├── LiteMark16.png
│   ├── LiteMark32.png
│   ├── LiteMark48.png
│   ├── LiteMark64.png
│   └── LiteMark128.png
└── README.md          # 说明文档
```

### 技术栈

- **Manifest V3**：使用最新的 Chrome 扩展 API
- **Service Worker**：后台脚本，处理右键菜单和 API 请求
- **Chrome Notifications API**：显示系统通知
- **Chrome Storage API**：存储配置信息
- **Chrome Context Menus API**：创建右键菜单

### 权限说明

扩展需要以下权限：

- `storage`：存储配置信息（API 地址、用户名、密码）
- `contextMenus`：创建右键菜单
- `tabs`：获取当前标签页信息
- `notifications`：显示系统通知
- `bookmarks`：读取浏览器收藏夹（用于导入功能）
- `host_permissions`：访问所有网站（用于添加书签）

## 常见问题

### 安装和配置

**Q: 扩展安装后右键菜单不显示？**
- 检查扩展是否已启用
- 尝试重新加载扩展（`chrome://extensions/` → 点击刷新图标）
- 刷新当前网页

**Q: 保存配置时提示"连接失败"？**
- 检查 LiteMark 地址是否正确（需要包含 `https://` 或 `http://`）
- 检查用户名和密码是否正确
- 检查网络连接
- 确保 LiteMark 服务正常运行

### 添加书签

**Q: 添加书签时提示"添加失败"？**
- 检查是否已正确配置扩展
- 检查 LiteMark 服务是否正常运行
- 查看浏览器控制台（F12）的错误信息

**Q: 分类菜单不显示或显示不全？**
- 分类菜单会缓存 5 分钟，等待缓存过期后会自动更新
- 或者重新加载扩展强制刷新

### AI 功能

**Q: AI 功能不可用？**
- 确保 LiteMark 后端版本 >= 2.0
- 确保后端已配置 AI 服务（OpenAI、Claude 等）
- 检查扩展配置中是否勾选了"启用 AI 智能添加"

**Q: AI 添加速度很慢？**
- AI 需要分析网页内容，通常需要 3-10 秒
- 处理过程中会显示"AI 正在处理"通知
- 请耐心等待，不要重复点击


### 通知功能

**Q: 添加书签后看不到通知？**
- 检查系统通知设置（见上方"通知权限设置"）
- 确保浏览器通知权限已启用
- 在 macOS 上，确保 Chrome 在"系统设置 → 通知"中已允许通知

**Q: 通知显示后立即消失？**
- 这是正常行为，成功通知会在 3-5 秒后自动消失
- 如果需要通知一直显示，可以在系统设置中将通知样式改为"提醒"

### 导入收藏夹

**Q: 导入收藏夹时部分书签失败？**
- 查看浏览器控制台的错误信息
- 可能是某些书签的 URL 格式不正确
- 失败的书签会记录在控制台中

**Q: 导入后分类不正确？**
- 确保勾选了"使用文件夹名称作为分类"
- 浏览器收藏夹的文件夹名称会作为 LiteMark 的分类
