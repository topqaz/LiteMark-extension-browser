# LiteMark 浏览器扩展

一键将网页添加到 LiteMark 书签管理系统。

## 功能特点

- 🔖 **右键菜单添加**：在任意网页右键，选择"添加到 LiteMark"
- 📥 **收藏夹导入**：一键导入浏览器收藏夹到 LiteMark
- 🔗 **链接快速添加**：右键点击链接直接添加
- 📝 **智能标题**：选中文本作为标题，或自动使用页面标题
- 🏷️ **分类管理**：自动加载分类，支持分类添加

## 快速开始

### 安装

1. **下载扩展**
   - 访问 [LiteMark 扩展下载页面](https://github.com/topqaz/LiteMark-extension-browser/releases)
   - 下载最新版本的扩展压缩包（如：`LiteMark-extension-1.0.0.zip`）
   - 解压到任意一个地方（**注意：目录不能含有中文**）

### 配置

1. 点击扩展图标
2. 输入 LiteMark 地址、用户名和密码
3. 点击"保存配置"

### 使用

- **添加当前页面**：网页空白处右键 → "添加到 LiteMark" → 选择分类
- **添加链接**：链接上右键 → "添加到 LiteMark" → 选择分类
- **导入收藏夹**：扩展弹窗 → "导入浏览器收藏夹"

## 技术说明

### 权限

1. 点击扩展图标打开配置页面
2. 输入你的 LiteMark 部署地址（如：`https://your-litemark.app`）
3. 输入管理员用户名和密码
4. 点击"保存配置"

### 2. 添加书签

配置完成后，你可以通过以下方式添加书签：

#### 右键菜单

- **添加当前页面**：在任意网页空白处右键，选择"添加到 LiteMark" → 选择分类（或无分类）
- **添加链接**：右键点击页面中的链接，选择"添加到 LiteMark" → 选择分类
- **标题获取方式**：
  - **选中文本**：如果选中了页面中的文本，会使用选中文本作为书签标题
  - **网站标题**：如果没有选中文本，会使用网站标题（页面 `<title>` 标签内容）
  - **链接文本**：如果右键点击链接且没有选中文本，会使用链接文本作为标题
- **选择分类**：右键菜单会显示所有已存在的分类，选择后书签会添加到对应分类中

### 3. 操作反馈

- ✅ 添加成功：会显示浏览器通知，提示书签已添加（包含分类信息）
- ❌ 添加失败：会显示错误通知，提示失败原因
- ⚠️ 未配置：会提示先配置 LiteMark 地址和登录信息

### 4. 分类菜单

- 分类菜单会自动从 LiteMark 中加载所有已存在的分类
- 分类列表会缓存 5 分钟，以提高性能
- 新添加的分类会在下次右键时自动显示
- 如果还没有分类，菜单中只会显示"无分类"选项

## 常见问题

- **右键菜单不显示**：检查扩展是否启用，尝试重新加载扩展
- **添加失败**：检查 LiteMark 地址、账号密码和网络连接
- **通知不显示**：检查浏览器通知权限
