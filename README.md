# LiteMark 浏览器扩展

一键将当前网页添加到 LiteMark 书签管理系统。

## 功能特点

- 🔖 **右键菜单添加**：在任意网页右键，选择"添加到 LiteMark"
- 🔗 **链接快速添加**：右键点击链接，直接添加到 LiteMark
- 📝 **选中文本添加**：选中文本后右键，将选中内容作为标题添加当前页面
- ⚡ **快速添加按钮**：在扩展弹窗中一键添加当前页面
- 🔐 安全的登录认证
- 💾 配置自动保存
- 🔔 操作结果通知提醒

## 使用方法

### 1. 首次配置

1. 点击扩展图标打开配置页面
2. 输入你的 LiteMark 部署地址（如：https://your-litemark.vercel.app）
3. 输入管理员用户名和密码
4. 点击"保存配置"

### 2. 添加书签

配置完成后，你可以通过以下方式添加书签：

#### 右键菜单

- **添加当前页面**：在任意网页空白处右键，选择"添加到 LiteMark" → 选择分类（或无分类）
- **添加链接**：右键点击页面中的链接，选择"添加到 LiteMark" → 选择分类
- **标题获取方式**：
  - **选中文本**：如果选中了页面中的文本，会使用选中文本作为书签标题
  - **网站标题**：如果没有选中文本，会使用网站标题（页面 `<title>` 标签内容）
  - **链接文本**：如果右键点击链接且没有选中文本，会使用链接文本作为标题
- **选择分类**：右键菜单会显示所有已存在的分类，选择后书签会添加到对应分类中


### 3. 操作反馈

- ✅ 添加成功：会显示浏览器通知，提示书签已添加（包含分类信息）
- ❌ 添加失败：会显示错误通知，提示失败原因
- ⚠️ 未配置：会提示先配置 LiteMark 地址和登录信息

### 4. 分类菜单

- 分类菜单会自动从 LiteMark 中加载所有已存在的分类
- 分类列表会缓存 5 分钟，以提高性能
- 新添加的分类会在下次右键时自动显示
- 如果还没有分类，菜单中只会显示"无分类"选项

## 开发说明

### 文件结构

```
extension/
├── manifest.json      # 扩展配置文件
├── popup.html         # 弹出窗口 HTML
├── popup.css          # 弹出窗口样式
├── popup.js           # 弹出窗口逻辑
├── background.js      # 后台服务脚本（处理右键菜单）
├── icons/             # 扩展图标（需要自行添加）
│   ├── icon16.png
│   ├── icon48.png
│   └── icon128.png
└── README.md          # 说明文档
```

### 权限说明

- `storage`: 保存配置信息（使用 Chrome Storage Sync API）
- `contextMenus`: 创建右键菜单
- `tabs`: 获取当前标签页信息
- `notifications`: 显示操作结果通知
- `host_permissions`: 访问 LiteMark API

### 图标制作

需要创建以下尺寸的图标：
- 16x16 像素
- 48x48 像素
- 128x128 像素

可以使用在线工具或设计软件制作，保存为 PNG 格式。

## 工作原理

1. **配置保存**：使用 `chrome.storage.sync` API 保存 LiteMark 地址和登录信息
2. **右键菜单**：扩展安装时自动创建右键菜单项
3. **Token 缓存**：登录后 Token 会缓存 1 小时，减少重复登录
4. **API 调用**：通过 LiteMark REST API 添加书签
5. **通知反馈**：使用 Chrome Notifications API 显示操作结果

## 注意事项

1. 首次使用需要配置 LiteMark 地址和登录信息
2. 配置信息会保存在浏览器本地（Chrome Sync），不会上传到任何服务器
3. Token 会在本地缓存 1 小时，过期后会自动重新登录
4. 如果配置更改，Token 缓存会自动清除
5. 需要网络连接才能添加书签

## 故障排除

### 右键菜单不显示

- 检查扩展是否已正确安装和启用
- 尝试重新加载扩展（在扩展管理页面点击刷新）
- 检查浏览器控制台是否有错误（F12）

### 添加失败

- 检查 LiteMark 地址是否正确
- 检查用户名和密码是否正确
- 检查网络连接是否正常
- 查看浏览器控制台错误信息（F12）
- 查看扩展后台脚本日志（扩展管理页面 → 服务工作者）

### 通知不显示

- 检查浏览器通知权限是否已授予
- 在浏览器设置中允许该扩展显示通知
